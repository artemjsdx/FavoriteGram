# Favourite Gram

Веб-интерфейс приватного мессенджера с регистрацией по юзернейму, поиском людей, личными чатами, голосовыми сообщениями и видеокружками.

## Что уже работает

- адаптивная гостевая главная с анимированным песочным WebGL-фоном;
- создание аккаунта и вход с deck-анимацией проверки пароля;
- экран кодов восстановления;
- поиск людей и создание нового диалога;
- отправка текстовых сообщений;
- запись и локальное воспроизведение голосовых через MediaRecorder;
- запись, пересъёмка и отправка видеокружка;
- загрузчик и круглый предпросмотр аватара;
- desktop/mobile-компоновка, клавиатурная навигация и reduced motion;
- WebMCP-действия для чтения списка чатов и отправки сообщения.
- сохранение локальной сессии, профиля, темы и истории между перезагрузками;
- серверные аккаунты и HttpOnly-сессии при запуске вместе с API;
- постоянная история чатов, загрузка файлов и realtime-события через SSE;
- серверные непрочитанные, presence и индикатор набора текста;
- одноразовые коды восстановления с реальной сменой пароля;
- удаление чата долгим нажатием или контекстным меню.

## Текущий статус

Проект работает в двух режимах:

- на обычном статическом хостинге используется локальный режим браузера;
- при запуске через `server/index.mjs` включаются серверные аккаунты, сессии,
  загрузки, синхронизация профилей и realtime-события.

Встроенная JSON-база рассчитана на один экземпляр приложения и первый
публичный прототип. Для горизонтального масштабирования её нужно заменить на
PostgreSQL, а каталог загрузок — на S3-совместимое хранилище.

## Локальный запуск

Требуется Node.js 22.13+ и pnpm 11.

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm build
pnpm start
```

Команда создаёт полностью статический сайт в каталоге `out/`. Для публикации
без backend достаточно отдать содержимое `out/` любому статическому хостингу.
`pnpm start` раздаёт этот каталог вместе с API на порту из переменной `PORT`.

## Wispbyte

Рекомендуемый вариант для полноценного мессенджера — импортировать этот GitHub
репозиторий в **Wispbyte** и запустить корневой `Dockerfile`.

- порт контейнера: `3000` (или значение `PORT`, которое задаст панель);
- постоянный том: `/data`;
- healthcheck: `/api/health`;
- необязательный `PUBLIC_ORIGIN`: `https://favourite.loc.cc`;
- домен `favourite.loc.cc` направляется на выданный Wispbyte hostname через
  CNAME. DNSSEC и существующие DS/DNSKEY менять не нужно.

Если панель запускает Node.js без Docker, команды такие:

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start:wispbyte
```

Каталог, указанный в `DATA_DIR`, должен быть постоянным между перезапусками.

## Проверка

```bash
pnpm lint
pnpm build
pnpm test
```

Интеграционный тест запускает production-сервер во временном каталоге и
проверяет два независимых аккаунта, профили, поиск, сообщения, файлы,
непрочитанные, удаление диалога, восстановление пароля и перезапуск процесса.

## Стек

- React 19, TypeScript, Next.js;
- Tailwind CSS и shadcn/ui;
- Framer Motion;
- Paper Design shaders;
- MediaRecorder API.
- Node.js HTTP API без runtime-зависимостей;
- Server-Sent Events для realtime-обновлений.

## Домен

Целевой домен — `favourite.loc.cc`. В DNS нужно добавить запись, которую выдаст выбранный хостинг. DNSSEC и существующие DS/DNSKEY при этом не меняются.
